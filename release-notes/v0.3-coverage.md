## Evidence boundaries

The NIMBY horror cases are fictional teaching scenarios. Named panel examples remain distinct accounts. RECEIPT, Promise Ledger, Stage Manager and Suspect Memories are labeled prototypes. The three-part evaluation program is proposed practice; no production integration or vendor-comparison result is claimed.
