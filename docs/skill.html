Install locally

git clone --branch codex/support-machine-v0.3 https://github.com/assafbar2/the-support-machine.git
mkdir -p ~/.codex/skills
cp -R the-support-machine/skills/the-support-machine ~/.codex/skills/
cp -R the-support-machine/skills/support-ai-evals ~/.codex/skills/

Load the installed skills in your agent. The review branch contains v0.3 until the edition is merged.

Use The Support Machine to compare buying, extending, and building our support agent.
Use The Support Machine to rehearse an action whose result is unknown.
