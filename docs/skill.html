The Support Machine

For the full migration and operating model: build versus buy, vendors, release gates, action safety, customer promises, recovery, and team design.

Download the skill ZIP · .skill package

Install in Claude

Leave the ZIP zipped. In Customize → Skills, choose + → Create skill → Upload a skill. Upload the ZIP and enable it. Code execution and file creation must be enabled; organization policy may control availability. Start with “Use The Support Machine skill to help me with [decision].”

Install in Codex

Ask the built-in installer:

$skill-installer Install skills/the-support-machine from GitHub repository assafbar2/the-support-machine, ref codex/support-machine-v0.3.

Invoke $the-support-machine followed by your task. Restart Codex if the skill does not appear. For manual installation, copy the complete skill folder, including references and templates, into ~/.agents/skills/.

Verify and update your copy

Ask the skill to read its bundled book reference, identify v0.3, and locate Chapter 28 and the build-versus-buy template. Install the new package when a new edition arrives; a local or uploaded copy does not automatically follow the GitHub repository. Keep company-specific notes separately.
